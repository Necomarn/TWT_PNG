# TWT Explained — GitHub Pages Website

Static HTML/CSS/JavaScript site with 14 enhanced screenshots and three locally hosted narrated videos.

## Publish on GitHub Pages
1. Create a new public GitHub repository (e.g. `twt-explained`).
2. Upload **the contents of this folder** to the repository root (`index.html`, `styles.css`, `script.js`, and `assets/`). Do not upload the ZIP itself.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then **main** and **/(root)**. Save.
5. Wait for GitHub to show the live Pages URL.

## Notes
- The website runs entirely on GitHub Pages; no build step or backend is needed.
- Image enhancement uses high-quality Lanczos resizing, modest sharpening, and contrast adjustment. It does not reconstruct missing detail or verify the images' content.
- Videos are the three supplied MP4s, copied without alteration.
- Screenshots and payment records are not independent verification of financial claims.
- Hiri Motu text/audio should be reviewed by a fluent speaker.
